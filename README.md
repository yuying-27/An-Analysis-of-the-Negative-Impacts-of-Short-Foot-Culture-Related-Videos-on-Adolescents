## 研究背景
慢脚文化是快手平台上以慢节奏、低俗、猎奇、负能量为特征的内容亚文化。
本研究关注其对青少年心理健康的影响，结合问卷调查与微博文本分析展开。

## 数据说明
- **问卷数据**：201 份有效样本，27 道题，双主体结构（受访者本人 + 观察到的青少年）
- **微博数据**：500 条与"慢脚"相关的微博（2023-2025）
- 详见 [变量说明.md](变量说明.md)

## 研究方法
1. 现象发现：微博文本分析（词频、情感、LDA 主题）
2. 接触画像：问卷 EDA
3. 影响实证：Q13 vs Q19 增量分析 + risk_score 风险得分
4. 风险识别：高风险人群画像
5. 议题互证与干预建议
